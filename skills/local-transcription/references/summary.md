# Practical dialogue summary

Use the complete reviewed dialogue. Distinguish a speaker's claims from verified facts, and distinguish settled decisions from examples, options, and unfinished discussion.

Include the useful takeaways, concrete approaches or formulas, applicable examples, and agreed next steps. Include timestamps for significant advice so the reader can find the source. Remove conversational filler from the summary, not from the transcript.

When assembling cleaner example wording from several passages, identify it as a synthesis rather than a verbatim quote. Preserve qualifications and uncertainty. Do not add advice, promises, facts, or action items that were not supported by the dialogue.

Use concise headings and lists when helpful. Write in the transcript's language unless the user specified another language. Save the Markdown beside the four transcript outputs and link it in the response.
